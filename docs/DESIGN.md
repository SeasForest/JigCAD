# JigCAD 设计说明（v0.1 MVP）

本文记录 MVP 的关键技术决策、它们如何对应 PRD 的五大诉求，以及后续路线图。

## 1. 关键决策

| # | 决策 | 选择 | 理由 |
|---|------|------|------|
| D1 | 几何内核 | **build123d（OpenCascade B-Rep）** | 成熟开源工业内核；pip 可装、完全离线；原生 STEP；Python 生态对 AI 最友好。仅 `geom.py`、`components/`、`engine.py`、`render.py`、`project.py` 接触内核，便于将来替换或并接其它底座（NFR：可维护） |
| D2 | AI 的建模语言 | **声明式 YAML 特征树**（组件 + 参数 + 锚点挂载 + 检查），`use: python` 作为逃生口 | 比让 AI 写内核脚本省 3~10 倍 token；可 diff、可回滚、可逐特征校验；语法面小，廉价模型也写得对 |
| D3 | “硬约束”实现方式 | **参数 + 表达式驱动 + 语义锚点**，暂不引入 2D 约束求解器 | 覆盖绝大多数功能件；确定性重建；定位全部来自包围盒或组件声明的锚点，**从不引用拓扑编号**，因此改参数后不会“断引用” |
| D4 | 定位方式 | `on: <feature>.<anchor>` + 局部 `at: [u,v,w]` + 引用参数/特征包围盒的表达式 | 消除 AI 心算三维绝对坐标；cut 永远沿法向往里切、add 永远沿法向往外长，方向错误可被机器判定 |
| D5 | 自检 | 逐特征即时校验 + 全局校验 + 用户声明的验收检查 | 错误在**产生它的那一步**被定位，而不是最后才发现“零件不对” |
| D6 | 视觉校验 | CLI 本地渲染 2×2 多视图 PNG（z-buffer + B-Rep 面边界描边 + 特征标注 + mm 标尺），由 Agent 自己看图 | 零云成本；不绑定任何 VLM；纯文本模型可改用 `inspect` 和探针检查 |
| D7 | 反馈格式 | 紧凑文本（默认）/ JSON（`--json`）；每条错误给出 `code [feature] 描述 + fix 建议` | 一个失败报告通常不到 300 字节，可直接指导下一步修改 |
| D8 | 状态安全 | 构建是“规格 → 几何”的纯函数；只在 PASS 时导出并存快照（`.jig/history`）；`restore` 前自动备份 | 试错永远不会覆盖已验证状态 |
| D9 | 复用沉淀 | `jig promote` 把通过的规格变成组合组件（YAML），自动从 `./components`、`$JIGCAD_PATH`、`~/.jigcad/components` 加载 | 越用越省：下次直接 `use: <组件>` |
| D10 | 运行安全 | 每个几何任务在子进程中执行，带超时；表达式 AST 白名单沙箱；特征数、实例数、嵌套深度设上限 | 防死循环、防卡死、防注入 |

## 2. 与 PRD 诉求的对应

| PRD 诉求 | MVP 中的落点 |
|---|---|
| 少造轮子 | OCCT 内核；20 个面向夹具/治具/外壳的组件；ISO 紧固件表（`size: M4, fit: insert`）；`repeat`（grid/polar/mirror）；`promote` 组合组件 |
| 硬几何约束与高精度 | 精确 B-Rep；STEP（固定时间戳，确定性输出）/STL/3MF/GLB/BREP；参数表达式驱动；几何指纹 `fp` 校验确定性 |
| 准确建模 | 语义锚点 + 局部偏移 + 表达式；不引用拓扑编号；边选择器 `of: <feature>` 只选该特征的原始边 |
| 自我检查 | 逐特征：`cut_missed`、`not_through`、`breakout`、`thin_wall`、`floating`、`add_buried`、`multi_wall`；全局：有效性、流形、实体数、包围盒、体积、质心、尺寸、探针点；另有多视图渲染 |
| 低 AI 成本 | SKILL.md 约 4 KB，参考文档按需加载；`comp list` 约 1.7 KB；报告几百字节；全部计算本地执行，零云费用 |

## 3. 目录结构

```
src/jigcad/
  cli.py            jig 命令行（子进程 + 超时）
  engine.py         特征树执行器 + 逐特征校验 + 全局校验
  components/       组件框架、内置组件、YAML 组合组件、python 逃生口
  geom.py           锚点框架、边选择器、点分类、射线求交
  expr.py           安全表达式求值
  standards.py      ISO 紧固件与工艺规则
  render.py         多视图渲染
  project.py        导出、报告、版本历史
skill/jigcad/       Agent Skill（SKILL.md + references/）
examples/           基准零件集（jig bench examples）
tests/              核心测试 + 缺陷注入测试
```

## 4. 验收指标的度量方式（MVP 已具备的手段）

- **工程精度达标率**：`jig bench <目录>`，统计每个基准零件的 bbox/dims/体积/质心/流形检查结果。
- **自检有效拦截率**：`tests/test_core.py` 中的缺陷注入用例覆盖切空、切反、浮空、埋入、破壁、薄壁、断开、尺寸偏差、探针不符、多墙误穿；可继续扩充为统计集。
- **端到端成功率 / 单零件成本**：下一步建立 Agent 评测集（自然语言需求 → 期望检查），记录轮次与 token 数。
- **组件复用率**：统计规格中 `use:` 落在组合组件与内置组件上的比例（待做 `jig stats`）。

## 5. 路线图

- **v0.2**
  - 装配：多零件、配合锚点、零件间干涉与间隙检查
  - 特征级缓存（按前缀哈希缓存 BREP），加速迭代
  - 更多组件：螺纹（修饰/实体）、卡扣、铰链、型材槽、文字雕刻、
    放样/扫掠
  - 检查：悬垂角/可打印性，以及按工艺的最小孔径和最小槽宽
- **v0.3**
  - 可选 2D 约束草图（SolveSpace 求解器），支持声明式几何约束
  - Agent 评测集与成本基准（廉价模型对比顶级模型）
  - `jig stats`：组件复用率统计
  - MCP 适配层，与 CLI 同一套语义
